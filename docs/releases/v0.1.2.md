## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Command-line parsing for Mojo with Python argparse's behaviour: sub-commands, typed and repeatable options, a remainder command, prefix abbreviation, and argparse's own usage-error messages.

## Highlights

- `-é` or `-q\xff` on the command line no longer aborts the process.
- Builds on the Mojo 1.3 nightly as well as 1.2.0.

## Changes

### Added
- Conda recipe (`recipe.yaml`).
- README install and quickstart block, one example, and badges for CI, latest release and license.

### Fixed
- A multi-byte or invalid UTF-8 byte after a dash no longer aborts the parser; the arguments parse as the Python `argparse` oracle does.
- `ArgumentParser` builds on Mojo 1.3.0.dev2026110305 (explicit empty `__deinit__`); it still builds on 1.2.0.
