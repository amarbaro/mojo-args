# mojo-args v0.1.0

**Released:** 2026-10-21 · **Commit:** `7353d4b` · **Previous:** first release

## What it does

Command-line parsing for Mojo with Python argparse's behaviour: sub-commands, typed and repeatable options, a remainder command, prefix abbreviation, and argparse's own usage-error messages.

## Highlights

- Same parse results and the same usage-error text as Python argparse on 75 argv cases, 34 of them errors.
- argparse's quirks included: unique-prefix abbreviation, ambiguous-prefix errors, `--` kept by a remainder, `--opt=value`, bundled short flags.
- 13x faster than argparse: 200k parses in 252 to 259 ms vs 3,346 to 3,367 ms; building a parser takes 0.05 ms vs 11.3 ms.

## Changes

First public release, no earlier version.

## Known limits

- `--help` output is simple and not checked against argparse.
- A sub-command usage error prints the top-level usage line, where argparse prints the sub-command's.
- Integers are Int64, ASCII digits only.

## Upgrade / run

```
git clone https://github.com/amarbaro/mojo-args && cd mojo-args && uv sync
mojo run -I src examples/quickstart.mojo
```
